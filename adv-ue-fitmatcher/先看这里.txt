ADV x UE 骨架对接 v3.1 -- 快速使用
================================

这个包是一条完整流程，两步都在同一个窗口里，单独可用，不依赖 v2 文件夹：

  1. Build 前：把 UE 有、ADV 没有的骨先补进 ADV
  2. Build 后：把 UE 原骨搬到 ADV 的位置、按定稿轴向对齐、再连约束

入口：把 launch_deform_link.py 拖进 Maya 2025 视口。
（v2 是另一个独立文件夹 ADV_UE_FitMatcher_v2，只做 Fit 匹配+UE 轴向对齐，两者互不依赖。）


----------------------------------------
第一步：Build 前补骨（按钮「补骨」）
----------------------------------------
点一次就做完下面这些，重复点不会重复建：

  - Spine4     在 Spine3 与 Chest 之间插入，位置取两者中点。
               Build 后它对应 UE 的 spine_04，Chest 对应 spine_05。
  - Neck 中段  给 Neck 开 inbetweenJoints=1（只要 1 根，UE 只有 neck_02 一根）。
               Build 后生成 NeckPart1，对应 UE 的 neck_02。
               如果已经是 ADV 默认的 2，会改成 1；已 Build 的场景改完要重新 Build 才生效。
  - 四肢扭转   给 Shoulder / Elbow / Hip / Knee 开 twistJoints=2。
               Build 后生成 ShoulderPart1/2、ElbowPart1/2、HipPart1/2、KneePart1/2，
               对应 UE 的 upperarm / lowerarm / thigh / calf 各自的 twist_01/02。
               其中 Elbow 与 Knee 是反序：Part1->twist_02、Part2->twist_01。

只改 FitSkeleton，不碰 UE。补完去 ADV 里正常 Build。

注意：ADV 不允许 twistJoints 与 inbetweenJoints 加在同一根骨上。
如果某根骨已经开过另一种，工具会明确报错停下，不会硬改。


----------------------------------------
第二步：Build 后匹配 + 约束（「执行」）
----------------------------------------
三个勾选框，默认全开：

  [x] 位置匹配   UE 骨的位置搬到对应 ADV 变形骨的位置上。
  [x] 朝向对齐   按下面这张定稿表对齐轴向（不看当前状态，绝对规则）。
  [x] 建立约束   point / orient / scale 三个约束，Maintain Offset。

朝向规则（在 adv_ue_deform_link.py 顶部 ORIENT_OFFSETS 表，可直接改）：

  脊柱 / 颈 / 头   (0,0,0)      与 ADV 同向，头骨朝上
  右臂             (0,180,0)    rotY180：X 反 / Y 不变 / Z 反
  右手             (90,0,180)   X 反 / Y<->Z 互换
  右腿             (0,0,0)      与 ADV 同向
  左臂/左手/左腿   与右侧相同   2026-10-19 在真实场景只读实测：左侧没被动过的骨相对 ADV 的朝向与右侧逐项一致

  语义：UE 世界旋转 = 偏移矩阵 x ADV 变形骨世界旋转（左乘）。
  手指与扭转骨沿用所在肢体的规则。

想让某区域只搬位置、不转朝向，把对应那行改成 None 即可。


----------------------------------------
界面与报错（3.1 起）
----------------------------------------
窗口分三个框：「1 Build 前 · 补骨」「2 Build 后 · 匹配与约束」「详细结果」（点标题条可折叠）。
- 路径框是灰底只读：不能手打，只能选中后点右边的 << 载入。
  选这棵树里任意一根骨都行；选成另一棵树的，会自动放到对的那一栏。
- 打开窗口会自动扫场景，各自唯一就直接填好。
- 报错和提示：窗口最下面一行彩色状态（绿=好、黄=有提示、红=要处理），
  完整内容同时打到 Maya 底部命令行和 Script Editor（前缀 [ADV_UE_Link]），可以直接复制。
- 检查会提醒 UE 骨上开着的 Segment Scale Compensate：绑定阶段可不管，
  烘焙动画 / 导出 FBX 进引擎前要关掉（引擎不认，带缩放的动画会对不上）。工具只提示，不自动改。


----------------------------------------
不会做的事
----------------------------------------
- 不 Build、不 ReBuild，Build 要你自己在 ADV 里点。
- 不改 ADV 变形骨的任何变换，ADV 侧全程只读。
- 不覆盖已有约束：目标上已有外来约束、残缺约束、动画输入、锁定通道，一律停下报错。
- 不蒙皮。工具只用于 UE 原骨蒙皮之前。
- 发现「映射表之外的 UE 骨」会阻断并点名。典型是复制/镜像/重复导入留下的带数字后缀的骨
  （如 clavicle_l1 带着整条左臂，原名 clavicle_l 反成空骨）：不处理的话那条臂的位置会一直是错的。
  处理办法：把子骨用"保持世界位置"的 Parent（不加 -relative）挂回原名骨，再删掉多余的那根。
- 缺骨不阻断：UE 没这根骨、ADV 没这根驱动骨，都只跳过并列原因，能连多少连多少。
  只有能匹配的主骨低于 40% 时，才判定「不是一对配套骨架」并明确提示。

一次执行是一个撤销块，Ctrl+Z 一次全回（匹配和约束一起回）。

测试状态
----------------------------------------
隔离 mayapy 合成回归 20/20、纯契约 5/5（v3 自包含后重跑，含补骨幂等）。
真实场景 changgui.ma 实跑验证（拆包前的同一份逻辑）：84 对匹配+约束，79 对位置/朝向 0 偏差，
所有 twist 与主骨同向，7 个 FK 控制器转动后 19 个抽样骨全部跟随 ADV。

尚未验证：真实 GUI 点按（只用代码调用验证过）、模型蒙皮变形、UE 往返。
合成测试证明的是逻辑，不等于你的角色已经跑通。
